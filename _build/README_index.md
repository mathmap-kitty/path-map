# 升學地圖首頁（index.html）

沒有 build script，`index.html` 是**手寫維護**的單一檔案（CSS、HTML、JS 都內嵌）。
改完直接 commit + push，GitHub Pages 約 1–2 分鐘後生效。

## 頁面結構

| 區塊 | id | 內容 |
|---|---|---|
| 下一站看板 | — | JS 從 `exams` 陣列算距離學測／分科的天數 |
| 升學路線圖 | `#route` | 43 站；`class="station enroll"`（青綠）＝校內作業站 |
| 入學管道指南 | `#lanes` | 六張卡：特殊選才／繁星／個人申請／四技申請入學／分發入學／運動績優 |

新增站點後跑一次順序檢查（見下方）。

## 每年要手動做的事

1. **簡章公告後核對所有日期**（繁星／個申簡章約 11 月初公告）。
   目前頁面上的繁星與個申日期來自甄選會「重要日期（**暫定**）」，簡章出來後要逐項對過，
   並更新 footer 的「資料更新」日期與那段來源說明。參考 `116重要日期_待審.md` 的整理格式。

2. **換學年度時要一起改的地方**（例如 116 → 117）：
   - `<title>` 與 h2「116 學年度升學路線圖」
   - 路線圖全部站點的 `data-date` / `data-end` 與顯示日期
   - JS 裡的 `exams` 陣列（學測、分科的起訖日）與 `pre` 陣列（英聽兩次考試）
   - 各管道卡「關鍵時間」段落裡的日期
   - `apply.html` / `star.html` 的年度切換（見 `README.md`）

3. **校內學習歷程行事曆換年度**。
   路線圖有 6 個校內學習歷程站（9/18 勾選、10/21–23 收訖明細、2/10 上傳截止、
   3/3–5 收訖明細、4/14 最後勾選、4/15–19 最後收訖明細），來源是學校每年公告的
   「上傳學習歷程檔案件數與時程圖（高三）」。**這份圖每年都會換日期，不能沿用。**

4. **重跑四技申請入學的「二階要不要到校」比例**。
   四技卡片內文寫了具體數字，換年度簡章後要重算，不然數字會過期。作法見下一節。

5. **運動績優那一段跟 `sport.html` 同步**（甄審甄試報名／考試／放榜日期）。
   詳見 `README_sport.md` 的「每年要手動做的事」。

## 四技二階比例怎麼重跑

四技卡片目前寫的是：

> 以 115 學年度簡章逐系清點，全部 602 個校系（組）／學程中，481 個（約 8 成）沒有排定
> 到校複試日期，二階只看學習歷程備審資料；其餘 121 個才另外辦面試、實作或術科。

判斷依據是簡章分則裡的**「第二階段複試日期」**欄位：值為 `---` 就是不用到校。
（抽查驗證過：屏科食科系內文寫「僅採學習歷程備審資料審查，不辦理面試」，日期欄正是 `---`；
雲科資工、屏科農園／森林有面試占分，日期欄就有 5/16。
不能改用「頁面上有沒有出現『面試』兩個字」來判斷——很多校系是寫「**不**辦理面試」。）

新年度簡章 PDF 進來後，把路徑換掉重跑：

```bash
python -c "
import re, collections, fitz
d = fitz.open(r'D:\gmail\114\03_註冊\簡章\115_四技簡章.pdf')
full = ''.join(d[i].get_text() for i in range(d.page_count))
vals = re.findall(r'第二階段複試日期\s*\n(.{0,25}?)\n', full)
c = collections.Counter('無' if v.strip().startswith('---') else '有' for v in vals)
print('校系總數', len(vals), '｜無到校複試', c['無'], '｜有到校複試', c['有'])
"
```

基準值（115 學年度）：`602 / 481 / 121`。

## 路線圖順序檢查

新增或修改站點後跑這個，確認沒有把日期排錯：

```bash
python -c "
import re, sys; sys.stdout.reconfigure(encoding='utf-8')
s = open('index.html', encoding='utf-8').read()
sts = re.findall(r'<li class=\"station([^\"]*)\" data-date=\"([^\"]+)\"', s)
prev = ''; bad = 0
for cls, d in sts:
    if d < prev: print('順序錯誤:', d); bad += 1
    prev = d
print('共', len(sts), '站；順序問題', bad)
"
```

## 幾個容易寫錯的地方

- **繁星錄取後的限制**：錄取生**不論放棄與否**，都不得報名同學年大學「個人申請」，
  也不得參加「四技申請入學」的第一階段篩選。放棄只換到分科測驗／分發入學這一條路；
  沒在期限內放棄，連分發入學都不能報。別寫成「放棄了就能再報個申」。

- **學習歷程的「上傳」和「勾選」是兩個不同上限**：
  上傳到校內平台是課程學習成果**每學期** 6 件、多元表現**每學年** 15 件；
  勾選送中央資料庫是課程學習成果**每學年** 6 件、多元表現**每學年** 10 件；
  個申時每校系再勾選課程學習成果至多 3 件、多元表現至多 10 件。三層不要混。

- **校內時程圖上的 2/12 是「退件補上傳申請」**，不是逾期補件。
  寫成逾期補件，學生會把 2/10 那個真死線當成有緩衝。

- **「政高」是志願選填平台的廠商**，不是主辦單位也不是學校，頁面上不出現這三個字。
